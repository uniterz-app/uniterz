## 暫定結論の要約

### 維持すべき中核構造

```
Pro料金
  ↓
分析・通知・レポート・ビジュアルのみ

無料の予想・ランキング
  ↓
成績や条件に基づいて Unit を無償付与
  ↓
Unit を商品交換に使用
```

### 作らない接続

- Pro 料金 → Unit 付与
- Pro 料金 → ランキング優遇
- Pro 料金 → 商品獲得確率上昇
- 現金 → Unit 購入
- Unit → 予想への賭け
- Unit → 現金・譲渡

### 法務論点の優先度（暫定）

| 論点 | 暫定評価 |
|---|---|
| 賭博罪 | 比較的抑えめ（要弁護士確認） |
| 資金決済法 | 比較的抑えめ（無償・分離を維持） |
| 景品表示法 | **最大論点**（PRO INSIGHT × 商品報酬。書面判断必須） |
| NBA 商標・ライセンス | 正規品の都度購入は要確認。ロゴ・画像利用は原則不可 |

| 個人情報保護法・プライバシー | 配送・海外提供・AI・不正検知・未成年が要確認 |
| Apple・Google 課金・審査 | Pro／Unit／現物の分離、Season Pass 商品区分が要確認 |

## 1. 賭博罪

### 関係する理由

Uniterz では、NBA などの試合結果を予想し、成績上位者が Unit を獲得し、Unit を商品に交換できる。

刑法 185 条は賭博を処罰対象としており、オンライン上のスポーツベッティングも名称にかかわらず違法となり得るため、「予想」「商品」「価値のある Unit」が組み合わさる以上、構造確認が必要となる。

### 現在の設計

Uniterz では、ユーザーが予想へ参加するときに以下を負担しない。

- 現金
- 有料購入した Unit
- 保有 Unit
- 商品
- その他の財産的価値

予想が外れても、ユーザーの Unit や財産は減らない。

商品代金は、参加ユーザーの支払金を集めた賞金プールではなく、**運営の事業資金から支出**する。

### 暫定評価

現在の構造では、ユーザー同士が財産の得喪を争う仕組みではなく、運営が一方的に無料報酬を提供する設計になっている。

そのため、一般的な賭博構造からは距離があり、賭博罪リスクは比較的低いと考えられる。

ただし、次の変更を行うとリスクが大きく上がる。

- 予想参加に現金を必要とする
- Pro 加入をランキング参加条件にする
- Unit を購入可能にする
- Unit を予想に賭けさせる
- 予想を外したら Unit を失う
- 参加者から集めた金銭を上位者へ配る
- Unit を現金へ換金できるようにする
- ユーザー同士で Unit を賭ける

### 必須実装条件

予想への参加は無料とし、予想の結果によってユーザーが既に保有する財産、Unit その他の利益を失うことはない。

以下も維持する。

- Free・Pro とも予想参加は無料
- Pro 料金は分析機能への対価
- Pro 料金から賞金プールを形成しない
- Unit は購入不可
- Unit は予想に使用不可
- Unit は換金・譲渡・販売不可
- 予想失敗による Unit 減少なし
- 商品費用は運営負担

### 弁護士への質問

1. ユーザーが金銭や Unit を賭けず、予想が外れても財産的損失を負わず、運営が自己資金から上位者へ Unit を無料付与する現在の設計は、刑法上の賭博または賭博場開張等図利に該当する可能性がありますか。  
2. Pro 料金が予想参加料や賞金原資と評価されないために、課金画面、利用規約、会計およびシステム上、どのような分離が必要ですか。

## 2. 景品表示法

### 関係する理由

景品表示法上の「懸賞」には、抽選だけでなく、クイズの正誤、作品、競技などの特定行為の優劣によって景品提供者を決める方法も含まれる。

したがって、総合スコアによる週間・月間ランキングやグループランキングは、景品表示法上の「懸賞」に該当する可能性がある。

ただし、懸賞であっても、商品・サービスの取引に付随していなければ、通常の景品規制の対象外となる可能性がある。

### 現在の設計で有利な点

- 無料会員だけで予想へ参加できる
- 無料会員もランキングへ参加できる
- 無料会員も Unit を獲得できる
- Free と Pro でスコア計算が同じ
- Free と Pro で Unit 付与量が同じ
- Free と Pro で商品交換条件が同じ
- Pro 加入を Unit 獲得条件にしていない
- Pro 加入者へのランキングボーナスがない

消費者庁は、無料会員登録だけを条件とする企画は、通常、それだけで取引に付随する景品提供にはならないと説明している。また、有料会員が参加者に含まれていても、有料会員が有利になる告知などがなく、企画全体が取引と切り離されていれば、直ちに景品規制の対象になるわけではないとしている。

### 最大の問題点：PRO INSIGHT

現在の設計で最も慎重に確認すべきなのは、Pro が有料の分析情報を提供すること。

消費者庁は、商品やサービスを購入することで、懸賞への応募が可能・容易になったり、クイズの答えやヒントが分かったりする場合、取引に付随すると判断される可能性があるとしている。

PRO INSIGHT は勝者を断言しないものの、以下の情報を提供する。

- MATCHUP EDGE
- RECENT CHANGE
- INJURY IMPACT
- SCHEDULE IMPACT
- UPSET FACTOR

これらが、Unit を獲得できるランキングで有料ユーザーの予想を実質的に有利にする情報と評価される可能性がある。

つまり、「Free と Pro でランキングルールが同じ」という条件だけでは、景品表示法上のリスクを完全には消せない。

### 景品規制の対象と判断された場合

一般懸賞に該当する場合、景品の最高額は次の範囲となる。

| 取引価額 | 景品最高額 |
|---|---|
| 5,000 円未満 | 取引価額の 20 倍 |
| 5,000 円以上 | 10 万円 |

さらに、景品総額は懸賞に関係する売上予定総額の 2％以内とされている。

仮に Pro 料金が取引価額と判断された場合の単純計算:

| プラン | 料金 | 20 倍 |
|---|---|---|
| Weekly | 280 円 | 5,600 円 |
| Monthly | 780 円 | 15,600 円 |
| Season Pass | 5,000 円 | 100,000 円上限 |

商品価格上限 25,000 円の NBA ジャージは、Weekly または Monthly の取引に付随する景品と判断された場合、最高額制限に抵触する可能性がある。

また、景品総額を Pro 売上予定額の 2％以内に収める必要が生じると、現在想定している Unit 配布制度の運営が難しくなる可能性がある。

### Unit を挟んでも回避できるとは限らない

景品類には物品、金銭、金券、便益、役務などの経済上の利益が含まれる。

Unit は現金ではないが、一定数を貯めることで最大 25,000 円の商品へ交換できる。

したがって、形式上は Unit を付与して後から商品交換する仕組みでも、実質的には商品を取得するための経済上の利益として評価される可能性がある。

「直接商品を配っていないから景品表示法の対象外」とは扱わない方が安全。

### リスクを下げる実装条件

#### 絶対に維持する条件

- Free だけでランキング参加可能
- Free だけで Unit 獲得可能
- Free と Pro の予想回数を同一にする
- Free と Pro のスコア計算を同一にする
- Free と Pro の Unit 付与量を同一にする
- Free と Pro の商品交換条件を同一にする
- Pro 加入ボーナス Unit を付けない
- Pro 限定の Unit ランキングを作らない
- Pro 限定イベントで商品を配らない
- Pro 加入者の当選確率を上げない

#### 課金画面で禁止する表現

- Pro ならランキングで有利
- Pro なら Unit を獲得しやすい
- 商品獲得への近道
- ランキング上位を狙える
- 勝率を上げてジャージを獲得
- PRO INSIGHT で Unit を稼ぐ

#### 画面上の分離

Pro 課金画面には、原則として次の表示を出さない。

- Unit 商品画像
- ジャージ交換の訴求
- ランキング報酬の訴求
- 「上位を狙おう」というコピー
- 商品交換までの Unit 進捗

Pro 課金画面は、分析・通知・レポート・ビジュアル機能だけを案内する。

### 暫定評価

景品表示法が最大の法務論点。

無料参加と同一条件によってリスクは下がっているが、PRO INSIGHT が予想成績に影響する有料情報である以上、景品提供が Pro 取引に付随しないと断定することはできない。

ここは弁護士から、**口頭ではなく書面で判断をもらう必要がある**。

### 弁護士への質問

1. Free ユーザーと Pro ユーザーで、予想回数、スコア計算、ランキング参加条件、Unit 付与量、商品交換条件を完全に同一とする場合、ランキング上位者への Unit および商品提供は、Pro 取引に付随しないオープン懸賞として扱えますか。  
2. Pro では勝者や推奨予想を表示せず、無料データを整理した分析情報のみを提供します。この PRO INSIGHT が、消費者庁 Q&A にいう「購入により答えやヒントが分かる」「応募が容易になる」事情として評価される可能性はありますか。  
3. Unit が無償付与され、一定数を貯めると商品へ交換できる構造では、景品類の価額は Unit 付与時、商品交換時、または最終的な商品の市場価格のどれを基準として判断しますか。  
4. 景品規制の対象になる場合、取引価額は Weekly の 280 円、Monthly の 780 円、Season Pass の 5,000 円のうち、どの金額を基準としますか。  
5. 現行設計を維持できない場合、Pro 機能、ランキング、Unit、商品交換をどのように変更すれば適法性を高められますか。

## 3. 資金決済法

### 関係する理由

Unit はアプリ内に数量として記録され、一定数を使うことで商品提供を受けられる。

そのため、資金決済法上の「前払式支払手段」に該当しないかを確認する必要がある。

### 現在の設計

Unit は以下の方法でのみ付与する。

- ランキング
- グループバトル
- 招待制度
- マイルストーン
- 特別イベント
- 無料キャンペーン

Unit は販売しない。

また、次の機能を持たせない。

- 現金購入
- Pro 加入特典としての付与
- 課金額に応じた付与
- 換金 / 払戻し
- 他人への譲渡 / 売買
- 外部ポイントへの交換
- Pro 料金への充当

### 暫定評価

金融庁は、対価を得ずに「おまけ」として発行されるものは、「対価を得て発行される」という前払式支払手段の要件を満たさず、原則として前払式支払手段には該当しないと説明している。

一方、名目上は無料でも、実質的に商品・サービスの料金にポイントの対価が含まれている場合は、前払式支払手段に該当する可能性がある。

現在の Unit は完全無償であり、Pro 料金とも分離されているため、資金決済法上の前払式支払手段に該当するリスクは比較的低いと考えられる。

### 危険になる変更

- Unit を 100 Unit＝1,000 円などで販売する
- Pro 加入時に Unit を付与する
- Pro 更新ごとに Unit を付与する
- 有料会員だけ Unit 倍率を上げる
- シーズンパスに Unit をセット販売する
- Unit を追加料金で補充できるようにする
- 有料 Unit と無料 Unit を同じ残高として混在させる
- 他社ポイントや暗号資産と交換可能にする
- ユーザー間で Unit を送金できるようにする

対価を得て発行するポイントは前払式支払手段となる可能性があり、無償分と有償分を混在させる場合には、表示上・帳簿上も明確な区分管理が求められる。

### 必須実装条件

#### Unit 付与システム

Unit 付与処理に、以下の項目を持たせる。

- `sourceType` / `sourceId`
- `grantedAmount` / `grantedAt` / `expiresAt`
- `isPaid: false`（すべての Unit について常に false）
- `reason` / `fraudStatus`

#### Pro 課金システム

Pro 課金処理から Unit 付与処理を呼び出さない。

```
Pro購入成功
  ↓
Pro利用権だけを有効化
  ↓
Unit残高は変更しない
```

#### 表示

利用規約・Unit 画面には以下を記載する。

> Unit は、運営が定める条件を満たしたユーザーへ無償で付与するアプリ内報酬です。Unit を購入することはできません。  
> Pro 利用料金は Pro 機能の利用対価であり、Unit の購入代金または商品交換の対価ではありません。

### 3 年の有効期限について

Unit に 3 年の有効期限を設けても、それだけで資金決済法の適用を回避できるとは限らない。

重要なのは有効期限ではなく、Unit の発行時にユーザーから対価を受け取っているかという点。

したがって、3 年期限は残高管理や運営負担のために設定するものであり、**法規制回避の根拠として扱わない**。

### 弁護士への質問

1. ランキング、招待、キャンペーン等でのみ無償付与し、購入、換金、譲渡および払戻しができず、指定商品との交換だけに使用できる Unit は、資金決済法上の前払式支払手段に該当しますか。  
2. Pro 利用料金と Unit 付与条件を完全に分離していても、同一アプリ内で Pro 課金と Unit 商品交換を提供することにより、Unit が実質的に対価を得て発行されたものと評価される可能性はありますか。  
3. 3 年の有効期限、商品交換上限および交換対象商品の限定について、資金決済法上必要または有効な対応はありますか。  
4. 規制対象外であることを明確にするため、利用規約、画面表示、会計台帳およびシステム上、どのような記録・分離が必要ですか。

## 4. NBA グッズ配布・商標・ライセンス

### 4-1. 関係する理由

Uniterz では、ユーザーが無償で獲得した Unit を使用し、以下の NBA 関連商品との交換を申請できる。

- NBA ジャージ
- NBA Tシャツ
- NBA キャップ

運営は申請を確認した後、NBA Store、Fanatics、Nike などの正規販売店から商品を購入し、ユーザーへ提供する。

この仕組みでは、主に以下の問題を確認する必要がある。

- 正規商品を景品・交換商品として提供するためのライセンス
- 「NBA」やチーム名の文字使用
- NBA・チームロゴの使用
- 選手名・選手画像の使用
- 販売店の商品画像・説明文の転載
- NBA 公認・提携サービスと誤認される表示
- 販売店の購入規約や転売・商用利用条件

### 4-2. 現在の商品提供方法

現在の設計では、Uniterz が NBA グッズを製造するのではなく、ユーザーから申請を受けた後に、正規販売店から真正な商品を都度購入する。

基本フロー:

```
ユーザー
  ↓ Unitによる交換申請
Uniterz
  ↓ 商品・価格・販売店を確認
正規販売店
  ↓ Uniterzが商品代金を支払う
ユーザーへ商品を配送
```

以下は行わない。

- NBA ロゴを使用した独自商品の製造
- チームロゴを印刷したオリジナル商品の製造
- 商品の改造や再加工
- 非正規販売店や転売市場からの仕入れ
- NBA グッズの一般販売
- ユーザーからの商品代金の徴収
- 商品購入による利益の上乗せ
- 正規品か確認できない商品の提供

### 4-3. 正規商品の提供とライセンス

正規販売店から真正な完成品を購入し、その商品を改造せずユーザーへ提供する行為は、NBA ロゴ入りの商品を自社で製造する行為とは異なる。

日本では、真正商品の並行輸入について、商標が権利者等により適法に付され、国内外の商標権者に一定の同一性があり、品質にも実質的な差がない場合には、商標権侵害に当たらないとする整理が示されている。もっとも、Uniterz の商品提供方法へそのまま適用できるかは、購入経路や商品の流通条件を含めた個別判断となる。

したがって、現時点では以下のように整理する。

正規品を購入して提供するだけで、NBA 商品の製造ライセンスが当然に必要になるとは限らない。ただし、継続的な商品交換制度としての提供、販売店規約、広告での商標使用を含め、**弁護士による確認が必要**である。

### 4-4. 商品提供と宣伝利用の分離

商品そのものを購入してユーザーへ渡せることと、NBA のロゴ、写真、商品画像などをアプリや広告で使用できることは **別問題**とする。

NBA の利用規約では、NBA や各チームに関するロゴ、写真、画像、統計、映像その他のコンテンツについて、権利者の書面による許可なしに、公開・商用目的で複製、表示、再利用等を行うことが制限されている。

オンラインストア側の規約でも、サイト上の商品画像、文章、グラフィック、ロゴなどを公開・商用目的で転載または使用することや、NBA 等の商標を許可なく使用することが制限されている。

そのため、以下の構造を維持する。

```
正規商品を購入して提供する
        ≠
販売店の商品画像やNBAロゴを自由に広告利用できる
```

### 4-5. アプリ内で使用しない素材

権利者から明示的な許諾を得るまでは、以下を商品交換画面、ランキング報酬画面、課金画面、広告等で使用しない。

- NBA 公式ロゴ
- NBA チームロゴ
- チームのユニフォームデザインを再現した画像
- 選手写真 / 試合写真
- NBA Store や Fanatics の商品画像
- Nike 等が撮影した商品写真
- NBA 公式サイトのスクリーンショット
- NBA 公式サイトの商品説明文の転載
- 選手の肖像を利用した独自イラスト
- NBA 公式と誤認されるアイコンやバナー

NBA の規約上、選手や人物の画像も、許可なく使用した場合、著作権、商標権、プライバシー権、パブリシティ権等の問題が生じる可能性がある。

### 4-6. 文字による商品説明

V1 では、商品画像やロゴを使用せず、**文字中心**で商品区分を表示する。

表示例:

> NBA ジャージ：1,000 Unit／商品価格上限 25,000 円  
> スウィングマンを基本とし、価格上限内であればオーセンティックも対象とします。  
>  
> NBA Tシャツ：600 Unit／商品価格上限 10,000 円  
>  
> NBA キャップ：300 Unit／商品価格上限 6,000 円

ただし、「NBA」という名称自体も商標であるため、商品内容を説明するための必要最小限の使用として許容されるか、具体的な画面や広告の文脈を弁護士に確認する。

以下のような、ブランドとの提携を示す使い方はしない。

- NBA 公式リワード / NBA 公認商品交換 / NBA 公式ジャージプレゼント
- NBA×Uniterz / Official NBA Partner / NBA Approved
- NBA から提供された商品

### 4-7. 非公認・非提携表示

商品交換ページや関連規約には、NBA との関係について誤認を防ぐ表示を設ける。

表示案:

> Uniterz は、NBA、NBA Properties, Inc.、各 NBA チーム、NBPA、商品メーカーおよび販売店から、公認、協賛または提携を受けたサービスではありません。  
>  
> 交換商品は、ユーザーの申請に基づき、Uniterz が承認した正規販売店から購入するものです。各商標および商品名は、それぞれの権利者に帰属します。

ただし、免責文を掲載しただけで、ロゴ、写真、商品画像等を自由に使用できるようになるわけではない。

### 4-8. 商品選択画面

ユーザーが交換を申請する際は、アプリ内に公式商品画像を転載するのではなく、以下の方式を基本とする。

1. ユーザーが正規販売店で希望商品を探す  
2. 商品ページの URL を申請フォームへ入力する  
3. 商品名、サイズ、カラー、価格を入力する  
4. 運営がリンク先を確認する  
5. 運営が正規販売店から商品を購入する  

ユーザーが商品画像を申請フォームへ添付する場合は、運営確認用として非公開で利用し、ランキング画面、商品一覧、SNS 広告等へ転載しない。

販売店へのリンクについても、NBA や販売店からの推薦・提携を示す表示にならないようにする。オンラインストアの規約では、リンク方法によって提携や承認を示唆することが制限されている例がある。

### 4-9. 販売店規約の確認

商品交換に使用する販売店ごとに、以下を確認する。

- 法人名義または事業目的で購入できるか
- 購入者と配送先が異なる注文が可能か
- 第三者への贈答・提供が可能か
- キャンペーンや報酬目的での購入が禁止されていないか
- 転売禁止条項の対象となるか
- 購入数量制限
- 海外配送の可否
- 返品・交換条件
- 画像・商品情報の使用条件
- 商品ページへのリンク条件

利用規約上の扱いが明確でない場合は、販売店へ書面で確認する。

確認先の候補: NBA Store / Fanatics / Nike / その他、運営が承認する正規販売店

販売店から許可を得ていない限り、「公式交換先」「提携販売店」などの表現は使用しない。

### 4-10. ライセンス取得が必要となる可能性が高いケース

以下を行う場合は、NBA、各チーム、選手側、メーカー等からライセンスまたは個別許諾が必要となる可能性が高い。

- NBA ロゴを Uniterz の画面や広告で使用する
- チームロゴをランキングや予想画面で使用する
- 選手写真を使用する
- 公式商品画像を商品一覧へ掲載する
- NBA ロゴ入りの独自商品を製造する
- Uniterz 独自デザインと NBA 商標を組み合わせる
- NBA 公式キャンペーンのように告知する
- NBA やチームが協賛しているように表示する
- NBA グッズを仕入れて一般ユーザーへ継続販売する
- 商品のパッケージを変更して Uniterz 商品として提供する

NBA の利用規約は、サイト上の知的財産について、サイトの利用によって商標や著作物の使用許諾が付与されるものではないと明記している。

### 4-11. 現在のリスク低減条件（V1）

- 正規販売店から真正な商品だけを購入する
- 商品を都度購入し、大量在庫を持たない
- 商品を改造・再加工しない
- NBA ロゴやチームロゴを使用しない
- 選手画像を使用しない
- 公式の商品画像を転載しない
- 商品説明は文字中心にする
- NBA 公認・提携・協賛を示す表現を使用しない
- Pro 課金画面で NBA グッズを強く訴求しない
- 販売店ごとの購入規約を保存する
- 必要に応じて販売店から書面回答を得る
- 商品の購入元、注文日、注文番号、真正品確認情報を保存する
- 非公認・非提携表示を設ける

### 4-12. 利用規約等への記載事項

利用規約または商品交換規約には、以下を記載する。

- 商品は運営が承認した正規販売店から購入すること
- 商品の在庫や販売を Uniterz が保証しないこと
- NBA 等から公認・提携を受けた制度ではないこと
- 商標、商品名等の権利が各権利者に帰属すること
- 販売店の返品・交換条件が適用されること
- 正規販売店の都合で商品を提供できない場合があること
- 商品画像をアプリ内へ無断転載しないこと
- ユーザーが入力した商品 URL・画像の利用目的
- 対象外販売店や非正規品を申請できないこと
- 知的財産権を侵害する商品は交換対象外とすること

### 4-13. 暫定評価

| 項目 | 暫定評価 |
|---|---|
| 正規品を都度購入して提供 | ライセンス不要の可能性があるが要確認 |

| 選手写真・公式商品画像の掲載 | 原則として使用しない |

現行設計では、商品を正規販売店から購入して提供する行為よりも、**NBA やチームの商標・画像をアプリや広告でどのように使用するかの方が大きなリスクになりやすい**。

### 4-14. 弁護士への確認事項

1. 正規販売店から真正な NBA 商品を都度購入し、無償付与した Unit との交換商品としてユーザーへ提供する場合、NBA、各チーム、メーカーその他の権利者からライセンスを取得する必要がありますか。  
2. Uniterz は商品代金をユーザーから受け取らず、運営資金で商品を購入します。この場合でも、商品の販売、再販売、景品提供または商標使用に関する許諾が必要となりますか。  
3. 「NBA ジャージ」「NBA Tシャツ」「NBA キャップ」という文字表記を、商品区分の説明としてアプリ内で使用できますか。  
4. NBA、チームのロゴ、選手画像、公式商品画像を使用せず、文字だけで商品を案内する設計であれば、商標権・著作権上のリスクを十分に下げられますか。  
5. ユーザーが正規販売店の商品 URL を申請フォームへ入力し、運営がその商品を購入する方法に問題はありますか。  
6. ユーザーが添付した商品画像を、運営確認用として非公開で保存する場合、著作権上どのような対応が必要ですか。  
7. NBA Store、Fanatics、Nike 等の販売店へ、キャンペーンまたは商品交換目的の購入について書面確認を取る必要がありますか。  
8. 商品交換ページに掲載する非公認・非提携表示として、どのような文言が適切ですか。  
9. 商品を販売店からユーザーへ直接配送する場合と、一度 Uniterz が受領してから発送する場合で、法的な扱いや責任に違いがありますか。  
10. 将来的に NBA ロゴ、チームロゴ、選手画像または商品画像を使用する場合、どの権利者からどの範囲の許諾を取得する必要がありますか。

## 5. 特定商取引法・消費者契約法

以下は、現在の Pro 課金設計を前提とした弁護士確認前の暫定設計とする。

### 5-1. 関係する理由

Uniterz では、アプリ内で以下の有料サービスを販売する。

| プラン | 料金 | 契約形態 |
|---|---|---|
| Weekly | 280円 | 7日ごとの自動更新 |
| Monthly | 780円 | 1か月ごとの自動更新 |
| Season Pass | 5,000円 | シーズン終了までの買い切り |

インターネット上で申込みを受けて有料サービスを提供する取引は、原則として特定商取引法上の「通信販売」に該当し得る。通信販売では、料金、支払方法、提供時期、解約条件、事業者情報などの表示が必要となる。

また、利用規約に「運営は一切責任を負わない」「理由を問わず返金しない」などの条項を設けても、消費者契約法上、不当な部分が無効になる可能性がある。

### 5-2. 特定商取引法上の取引構造

Pro 料金は以下のデジタルサービスの利用対価とする。

- PRO INSIGHT
- 試合直前アラート
- 週次レポート
- 月次レポート
- Pro Skin
- Pro バッジ
- My Rank 専用表示
- その他の Pro 限定機能

以下は Pro 料金の対価に含めない。

- Unit
- 商品交換権
- ランキング上の加点
- Unit 付与倍率
- 予想回数の増加
- 商品獲得確率の上昇

購入画面、利用規約、会計処理、システム処理のすべてで、Pro 課金と Unit・商品交換を分離する。

### 5-3. 特定商取引法に基づく表記

アプリまたは公式 Web サイトに「特定商取引法に基づく表記」ページを設置する。

最低限、以下を掲載する。

| 表示項目 | 記載内容 |
|---|---|
| 販売事業者 | 設立後の法人名 |
| 代表者または責任者 | 代表取締役または通信販売責任者 |
| 所在地 | 法人の正式な所在地 |
| 電話番号 | 消費者からの問合せに対応できる番号 |
| メールアドレス | サポート用アドレス |
| 販売価格 | 各プランの税込価格 |
| 価格以外の負担 | 通信料金等。追加料金がある場合は内容と金額 |
| 支払方法 | App Store、Google Play 等 |
| 支払時期 | 購入確定時または各ストア所定の時期 |
| サービス提供時期 | 購入情報確認後、原則直ちに有効化 |
| 自動更新 | Weekly・Monthly が自動更新であること |
| 契約期間 | Weekly、Monthly、Season Pass の期間 |
| 解約方法 | 各ストアの管理画面から手続すること |
| 解約の効果 | 支払済み期間終了まで利用できること |
| 返金条件 | ストアの返金手続および法令に従うこと |
| 動作環境 | 対応 OS、対応端末、通信環境 |
| Season Pass | 対象シーズンと終了日 |

通信販売の広告では、事業者名、住所、電話番号、価格、支払時期・方法、サービス提供時期、解除条件、追加負担、ソフトウェアの動作環境などが表示事項とされている。

法人設立前の個人名義で販売する場合は、個人事業者としての氏名、事業拠点の住所、電話番号等の表示が必要となる可能性があるため、法人化前に課金を開始する場合は弁護士へ別途確認する。

### 5-4. 購入画面と最終確認画面

ユーザーが購入を確定する直前の画面で、契約内容を一覧で確認できるようにする。

最終確認画面では、少なくとも以下を表示する。

- プラン名
- 料金
- 税込価格
- 利用期間
- 利用可能な機能
- 月次レポート提供の有無
- 無料体験の有無
- 無料体験終了日時
- 無料体験終了後の請求額
- 初回請求予定日
- 自動更新の有無
- 次回以降の更新周期
- 解約方法
- 解約しても期間終了までは利用できること
- Season Pass の終了日
- 利用規約へのリンク
- プライバシーポリシーへのリンク
- 特定商取引法に基づく表記へのリンク

特定商取引法では、インターネット通販の最終確認画面に、数量・価格、支払時期・方法、提供時期、申込期間、解除条件などを表示し、申込内容を容易に確認・訂正できるようにする必要がある。誤認させる表示も禁止されている。

App Store や Google Play の購入シートが表示される場合でも、ストア画面だけで日本法上の表示義務を十分に満たすかは断定せず、Uniterz の購入画面にも主要条件を表示する。

### 5-5. 購入ボタンの表示

購入ボタンは、押すことで有料契約または自動更新契約が成立することを明確にする。

**Weekly の表示例**

- 7日間無料で開始
- 無料期間終了後は 280円／7日で自動更新されます。

**Monthly の表示例**

- 7日間無料で開始
- 無料期間終了後は 780円／月で自動更新されます。

**Season Pass の表示例**

- 5,000円で購入
- 2026–27シーズン終了日まで利用できます。自動更新はありません。

以下のような、契約成立が分かりにくいボタン表記は使用しない。

- 続ける
- 次へ
- 無料で試す

単独で使用せず、近接する位置に料金、自動更新、請求時期を表示する。

### 5-6. 7日間無料体験

Weekly および Monthly の初回利用者に、7日間の無料体験を提供する。

購入確定前に以下を明示する。

- 無料期間は 7日間
- 無料体験の開始日時
- 無料体験の終了予定日時
- 終了後に自動課金されること
- 終了後の料金
- 選択した更新周期
- 課金を避けるための解約方法
- 解約手続の期限
- Season Pass には無料体験がないこと
- Weekly 体験では月次レポートを利用できないこと

無料であることだけを大きく表示し、自動更新条件を小さく目立たない場所に置かない。

誤認させる最終確認画面により申込みを行った場合、消費者が契約を取り消せる可能性があり、事業者は行政処分等の対象にもなり得る。

### 5-7. Weekly・Monthly の自動更新

Weekly と Monthly は自動更新とする。

| プラン | 契約期間 | 更新周期 | 更新料金 | 備考 |
|---|---|---|---|---|
| Weekly | 7日間 | 7日ごと | 280円 | 解約しない限り自動更新 |
| Monthly | 1か月 | 1か月ごと | 780円 | 解約しない限り自動更新 |

購入画面と特商法表記には、最低購入回数がないこと、いつでも自動更新を停止できること、停止後も現在の期間終了までは利用できることを記載する。

解約期限がストアごとに定められている場合は、「更新日の 24時間前まで」などの条件を記憶で記載せず、各ストアの最新仕様を確認して表示する。

### 5-8. Season Pass

Season Pass は定期購入ではなく、対象シーズン終了まで利用できる買い切りプランとする。

購入前に以下を表示する。

- 対象シーズン
- 購入価格
- 利用開始日
- 利用終了日
- 自動更新されないこと
- 次シーズンは再購入が必要であること
- シーズン途中で購入しても終了日は変わらないこと
- 購入時期による日割り返金を行わないこと
- 提供される Pro 機能

「シーズン終了まで」だけではなく、可能な限り具体的な終了日を表示する。

NBA の試合日程変更等により終了日を変更する可能性がある場合は、終了日の定義と変更条件を規約に記載する。

### 5-9. 解約方法

Weekly・Monthly の解約は、購入したストアのサブスクリプション管理画面から行う。

アプリ内には以下を設置する。

- 現在のプラン
- 自動更新状態
- 次回更新日
- 次回請求予定額
- 利用期限
- サブスクリプション管理画面へのリンク
- 購入の復元ボタン
- 解約方法の説明

解約手段を不必要に複雑にしない。

特定商取引法では、解約条件、方法、効果、不利益がある場合は、その内容を分かりやすく表示する必要がある。解約窓口を表示していても実質的に利用できない場合は、表示義務違反となるおそれがある。

### 5-10. 退会・アプリ削除と定期購入

以下の 3つを別の手続として扱う。

| 手続 | 効果 |
|---|---|
| アプリ削除 | 定期購入は原則継続 |
| Uniterz アカウント退会 | ストアの定期購入は自動解約されない場合がある |
| ストアでの解約 | 次回以降の自動更新を停止 |

退会画面には、次の警告を表示する。

> アカウントを削除しても、App Store または Google Play の定期購入は自動的に解約されない場合があります。退会前にサブスクリプション管理画面で契約状況を確認してください。

有効な定期購入がある状態で退会しようとした場合は、契約状況と解約導線を表示する。

### 5-11. 通信販売のクーリング・オフ

通信販売には、訪問販売などにある一般的なクーリング・オフ制度はない。

ただし、これを理由に「一切の返金・取消しを認めない」とは記載しない。

実際の返金は以下に従う。

- App Store または Google Play の返金手続
- 重複請求の有無
- 不正決済の有無
- Pro 機能が提供されなかった期間
- 法令上の取消し・返金義務
- 運営側の重大な障害
- 消費者契約法上の条項の有効性

### 5-12. 返金方針

基本方針は以下とする。

- ユーザー都合による途中解約では日割り返金を行わない
- 解約後も支払済み期間終了まで利用できる
- ストア経由の購入はストア所定の返金手続に従う
- 重複請求、誤請求、不正決済は個別に確認する
- 運営側の重大な障害でサービスを提供できなかった場合は個別対応する
- 法令上返金が必要な場合は法令に従う
- 返金成立後は、該当期間の Pro 利用権を終了できる

次のような絶対的な条項は使用しない。

- 理由を問わず返金しません。

代わりに以下のように記載する。

> 購入後の返金は、購入したストアの返金方針および適用法令に従います。重複請求、当社の責めに帰すべき重大なサービス提供不能その他個別対応が必要な場合は、サポート窓口で確認します。

### 5-13. 消費者契約法上の免責

消費者契約法では、事業者の債務不履行等による損害賠償責任を全面的に免除する条項や、事業者が責任の有無を自由に決定できる条項は、無効となり得る。

以下の条項は使用しない。

- 運営は一切責任を負わない
- いかなる場合も損害賠償しない
- 運営が責任を負うかどうかは運営のみが決定する
- 運営の故意または重大な過失があっても責任を負わない
- システム障害による損害はすべてユーザーが負担する

免責条項を設ける場合は、少なくとも以下を区別する。

- 運営の故意または重大な過失
- 運営の通常の過失
- 外部 API や通信会社等の第三者原因
- ユーザーの端末・通信環境
- 不可抗力
- 間接損害や特別損害
- 賠償上限

損害賠償上限を設定する場合も、運営の故意・重大な過失を適用除外とし、金額が著しく低すぎないかを弁護士に確認する。

### 5-14. 解約違約金・キャンセル料

現行設計では、Weekly・Monthly の解約に違約金やキャンセル料を設定しない。

Season Pass についても、中途解約時に追加の違約金を請求しない。

消費者契約法上、解除に伴う違約金や損害賠償予定額が、同種契約の解除により事業者へ生じる平均的な損害を超える場合、その超過部分は無効となる。

そのため、以下は行わない。

- 解約手数料
- 退会手数料
- 自動更新停止手数料
- 残存期間分とは別の違約金
- 解約を理由とした Unit 没収
- 解約を理由とした Achievement 実績の削除

Pro 終了後はスキン等の使用権を停止するが、これは契約期間終了に伴う有料機能の停止として扱い、罰則として設計しない。

### 5-15. サービス変更条項

運営は、Pro 機能の改善や変更を行えるものとする。ただし、規約に「運営はいつでも自由にすべての機能を廃止でき、ユーザーは異議を述べられない」とだけ記載するのは避ける。

消費者の権利を制限し、義務を加重する条項で、民法等の基本原則に反して消費者の利益を一方的に害するものは、消費者契約法第 10 条により無効となり得る。

変更条項には以下を含める。

- 変更する合理的な理由
- 変更内容
- 効力発生日
- 事前告知期間
- ユーザーへの影響
- 重大な不利益変更時の対応
- 購入済み期間への適用
- 解約または返金対応の有無

料金、契約期間、主要機能を大きく変更する場合は、購入済み期間へ遡及適用しないことを基本とする。

### 5-16. サービス停止・障害

以下の場合は、一時的にサービスを停止できるものとする。

- 定期メンテナンス
- 緊急メンテナンス
- 外部 API 障害
- ストア障害
- 通信障害
- サイバー攻撃
- 天災
- 法令または行政機関からの要請
- その他、合理的に運営継続が困難な場合

ただし、長期間にわたり主要な Pro 機能を提供できない場合まで、すべて免責する設計にはしない。

重大な提供不能が発生した場合は、以下を検討する。

- 利用期間の延長
- 一部返金
- 次回請求の停止
- 代替機能の提供
- 個別案内

### 5-17. Pro 機能に関する保証の範囲

PRO INSIGHT、通知、レポートについて、以下は保証しない。

- 試合結果との一致
- 予想の的中
- データの完全性
- 常時リアルタイムであること
- 通知の必達
- ランキング上昇
- Unit 獲得
- 商品交換への到達

ただし、「正確性を一切保証せず、誤りがあっても一切責任を負わない」という全面免責にはしない。

表示案：

> 本サービスの分析情報は、外部データ、独自の計算および AI 処理等に基づく参考情報です。試合結果、予想の的中、ランキング順位または Unit の獲得を保証するものではありません。
>
> 当社は情報の品質維持に努めますが、外部データの遅延、訂正、通信障害その他の事情により、表示内容に遅延または誤りが生じる場合があります。

## 6. 個人情報保護法・プライバシーポリシー設計

以下は、現在の Uniterz の仕様を前提とした弁護士確認前の暫定設計とする。

なお、個人情報保護法の改正法が 2026年7月17日に公布されており、主要部分は公布から 2年以内に施行予定である。以下は現行ルールを基準としつつ、施行内容が確定した段階で再確認する。

### 6-1. 基本方針

Uniterz は、サービス提供に必要な範囲でのみ個人情報・利用者情報を取得する。

以下を基本原則とする。

- 利用目的を具体的に定める
- 目的に必要のない情報を取得しない
- 公開情報と非公開情報を分離する
- 配送情報を通常プロフィールと分離する
- Pro 課金情報と Unit 履歴を分離する
- 不正検知情報へのアクセスを限定する
- 外部事業者へ必要以上の情報を渡さない
- 保存期間終了後は削除または匿名化する
- ユーザーが請求できる窓口を設ける

### 6-2. 取得する情報

#### アカウント・プロフィール情報

| 情報 | 用途 | 公開範囲 |
|---|---|---|
| ユーザー ID | アカウント識別 | 非公開 |
| メールアドレス | ログイン、本人確認、連絡 | 非公開 |
| 表示名 | プロフィール、ランキング | 公開 |
| ユーザー名・ slug | プロフィール URL | 公開 |
| プロフィール画像 | プロフィール表示 | ユーザー設定に従う |
| 自己紹介 | プロフィール表示 | ユーザー設定に従う |
| 登録日時 | 運営管理、不正確認 | 非公開 |
| 利用言語・地域 | 表示、通知、サポート | 非公開 |

生年月日、性別、本名などは、サービス提供上必要でなければ登録必須にしない。

- グループバトル成績
- レポート生成に使用する成績
- Achievement の達成状況

他ユーザーへ表示する範囲と、運営だけが使用する内部データを分離する。

クレジットカード番号や銀行口座情報は、原則として Uniterz 側では取得・保存せず、Apple・Google 等の決済事業者に処理させる。

#### 商品配送情報

### 6-6. AI を利用した分析

- 配送情報と AI 処理を接続しない
- 入力データを AI 事業者の学習に使用させない契約・設定を選ぶ
- AI 事業者、送信項目、利用目的を管理台帳へ記録する
- AI が生成した文章だけでアカウント停止や Unit 取消しを決定しない

不正判定やアカウント停止など重大な措置は、AI の判定のみで自動確定せず、運営による確認を挟む。

### 6-7. 委託先

以下の事業者へ個人データの取扱いを委託する可能性がある。

- クラウド・データベース事業者
- Firebase 等の認証・保存サービス
- Apple・Google 等の決済事業者
- プッシュ通知事業者
- メール配信事業者
- アクセス解析・障害解析事業者
- カスタマーサポート事業者
- 配送会社
- 商品販売店
- 不正検知・セキュリティ事業者
- AI 処理事業者

委託先には必要な情報だけを提供し、適切な事業者の選定、契約、安全管理状況の確認を行う。

個人データの取扱いを委託する場合、委託元には委託先を適切に選定し、安全管理が行われるよう監督する義務がある。配送のため宅配業者へ住所等を渡すことも、委託として整理される例が示されている。

### 6-8. 第三者提供

法令上認められる場合を除き、本人の同意なく個人データを第三者へ提供しないことを基本とする。

提供が想定される場合は、以下を明確にする。

- 提供先
- 提供目的
- 提供する情報
- 提供方法
- 提供停止の可否
- 保存期間

第三者提供を予定している場合は、その内容を利用目的でも明確にする必要があり、原則として事前の本人同意が必要となる。

以下は区別して管理する。

| 区分 | 例 |
|---|---|
| 委託 | 配送会社、クラウド運営、サポート業務 |
| 第三者提供 | 独自目的で情報を利用する外部事業者への提供 |
| 法令対応 | 裁判所、警察その他法令に基づく照会 |
| 外国提供 | 海外販売店、海外配送会社、海外クラウド |

### 6-9. 海外事業者への提供

海外ユーザーへ商品を直接配送する場合、氏名、住所、電話番号等を海外販売店または配送事業者へ提供する可能性がある。

この場合、商品交換申請時に以下を表示する。

- 提供先となる事業者
- 提供先の国・地域
- 提供する情報
- 商品注文・配送のために使用すること
- 提供先における個人情報保護措置
- 同意しない場合は直接配送を利用できないこと

外国にある第三者へ個人データを提供する場合、一定の例外を除き、外国提供を認める本人の同意が必要となる。本人の同意を取得する場合は、その国の制度や提供先の保護措置等の情報提供も必要となる。

プライバシーポリシーへの包括的な記載だけで済ませず、海外から直接発送する商品交換申請時に個別確認を表示する。

同意例：

> 商品の購入および配送のため、入力した氏名、住所、電話番号その他必要な情報が、選択した商品を販売・配送する海外事業者へ提供されることに同意します。

提供先が商品申請時まで確定しない場合は、確定後、購入前に情報を提示して同意を取得する。

### 6-10. 外部送信・SDK

アプリや Web サイトに外部 SDK、Cookie、アクセス解析機能等を導入する場合、以下の一覧を作成する。

| 項目 | 記載内容 |
|---|---|
| 送信する情報 | 端末情報、IP アドレス、操作履歴等 |
| 送信先 | Google 等の事業者名 |
| Uniterz での目的 | 障害解析、利用状況分析等 |
| 送信先での目的 | SDK 提供事業者の利用目的 |
| 無効化方法 | 設定、オプトアウト等 |
| 保存期間 | 確認できる場合に記載 |

プライバシーポリシーとは別に「外部送信に関する表示」を設け、電気通信事業法上の外部送信規律が Uniterz へ適用されるか弁護士へ確認する。

未使用の広告 SDK や分析 SDK を最初から組み込まない。

### 6-11. 不正検知情報

複数アカウントや招待制度の不正防止に、端末情報、IP アドレス、登録日時、予想投稿パターン等を利用できる。

ただし、以下を維持する。

- 不正防止という利用目的を明記する
- 必要な情報だけを取得する
- 同一 IP だけで不正と確定しない
- 同一端末だけで永久停止しない
- 重大な措置の前に複数情報を確認する
- 不正調査情報を一般従業員へ公開しない
- 不正検知情報を広告目的に利用しない
- 調査終了後、必要以上に長期間保存しない

家族や同居人が同じ通信環境を利用している可能性を考慮する。

### 6-12. 保存期間

保存期間は取得目的と法令上の必要性に応じて設定する。

初期案は以下とする。

| 情報 | 保存期間の初期案 |
|---|---|
| アカウント情報 | 退会まで |
| 通常プロフィール | 退会後 30日以内に削除 |
| バックアップ内情報 | 退会後 90日以内に順次削除 |
| 予想・ランキング | 運営・ランキング保全に必要な期間。退会後は匿名化を基本 |
| Pro 購入履歴 | 法令、税務、紛争対応に必要な期間 |
| Unit 台帳 | Unit 失効後も一定期間保存 |
| 商品注文履歴 | 配送完了後 3年間を暫定基準 |
| 配送先住所 | 配送・返品対応終了後、不要になり次第削除 |
| 問い合わせ履歴 | 対応完了後 3年間を暫定基準 |
| アクセス・セキュリティログ | 1年間を暫定基準 |
| 不正調査記録 | 調査完了後 3年間を暫定基準 |
| 外部提供記録 | 法令で必要な期間 |

第三者提供に関する記録には、作成方法に応じて 1年または 3年などの法定保存期間が定められている。

具体的な期間は、利用規約、税務上の保存義務、ストア記録および紛争対応を含めて弁護士・税理士へ確認する。

### 6-13. 退会時の処理

ユーザーが退会した場合は、以下を行う。

- ログインを無効化
- 公開プロフィールを非表示
- プッシュ通知を停止
- 通常 Pro Skin・Achievement Skin を非表示
- 未使用 Unit を失効
- 未処理の商品交換申請を確認
- 個人情報の削除または匿名化を開始

以下の情報は、法令や不正対応上必要な場合、一定期間保存できるものとする。

- 課金・返金記録
- Unit 付与・取消し記録
- 商品注文・配送記録
- 不正行為記録
- 法令上必要な第三者提供記録
- 紛争対応に必要な情報

保存する場合でも、利用目的を法令対応・不正防止・紛争対応に限定する。

### 6-14. 開示・訂正・削除等の請求

ユーザーが以下の請求を行える窓口を設ける。

- 利用目的の確認
- 保有個人データの開示
- 内容の訂正
- 情報の追加・削除
- 利用停止
- 消去
- 第三者提供の停止
- 第三者提供記録の開示

プライバシーポリシーには、事業者名・住所・代表者、利用目的、請求方法、安全管理措置の概要、苦情窓口等を、ユーザーが確認できる状態に置く必要がある。

請求時は、アカウントへのログイン、登録メールアドレス、本人確認コード等で本人確認を行う。

社内対応目標は、原則 30日以内とする。ただし、法令上対応できない場合や、不正調査・第三者の権利を侵害する場合は、理由を説明した上で全部または一部を拒否できるものとする。

### 6-15. 安全管理措置

個人データの漏えい、消失、改ざん等を防止するため、以下を実装する。

**組織的措置**

- 個人情報管理責任者を設定
- データ取扱規程を作成
- 管理者権限を持つ担当者を限定
- 操作ログを記録
- 委託先台帳を作成
- 定期的な権限確認

**技術的措置**

- 通信の暗号化
- 保存データの適切な暗号化
- 管理者アカウントの多要素認証
- Firestore 等のセキュリティルール設定
- 本番環境と開発環境の分離
- API キー・秘密情報の安全管理
- 不正ログイン検知
- レート制限
- 脆弱性の定期確認
- バックアップと復元手順

**人的措置**

- 権限を持つ者への教育
- 守秘義務
- 個人情報の外部持出し制限
- 退職・担当変更時の権限削除

事業者には、取扱情報の性質、量、事業規模、漏えい時の影響等に応じた必要かつ適切な安全管理措置が求められる。

### 6-16. 漏えい・不正アクセス時の対応

以下の対応手順を事前に作成する。

- アクセス・処理の停止
- 被害範囲の特定
- 漏えいした情報の確認
- 原因の調査
- パスワード・鍵・トークンの失効
- 二次被害防止
- 委託先との連携
- 個人情報保護委員会への報告要否の判断
- 対象ユーザーへの通知
- 再発防止策の実施

法令上の報告対象となる漏えい等については、状況に応じて速やかに本人へ通知する必要があり、委託先で発生した事故でも委託元・委託先間の連携が必要となる。

緊急連絡先、対応責任者、外部弁護士、クラウド事業者への連絡方法を事前に登録する。

### 6-17. 未成年ユーザー

未成年者が利用する可能性があるため、以下を決める。

- 利用可能な最低年齢
- 保護者同意が必要となる年齢
- Pro 課金時の保護者同意
- 商品配送時の氏名・住所取得
- 海外事業者への情報提供同意
- 未成年者からの削除請求方法

本人が同意の結果を判断できる能力を有しない場合、親権者や法定代理人等から同意を得る必要があるとガイドラインで示されている。

具体的な年齢基準は、利用国、ストア規約、民法上の契約能力を含めて弁護士に確認する。

### 6-18. 海外ユーザー

海外ユーザーへ提供する場合、日本の個人情報保護法だけで十分とは限らない。

対象地域によって、以下の対応が追加で必要になる可能性がある。

- EU・EEA の GDPR
- 英国 UK GDPR
- 米国各州のプライバシー法
- 韓国、カナダ、オーストラリア等の制度
- Cookie・分析 SDK に関する同意管理
- 地域別プライバシー通知
- データ移転契約
- プライバシー請求窓口

V1 で海外展開する国を決め、その国ごとに対応範囲を確認する。

### 6-19. 画面上の実装

**アカウント登録時**

- 利用規約へのリンク
- プライバシーポリシーへのリンク
- 登録に必要な情報の説明
- 公開される情報の説明
- 任意項目と必須項目の区別

**通知設定時**

- 通知の種類ごとの ON・OFF
- マーケティング通知とサービス通知を分離
- 通知を拒否しても基本機能を利用可能

**商品交換時**

- 配送情報の利用目的
- 販売店・配送会社への提供
- 海外事業者への提供可能性
- 保存期間
- 同意チェック
- 商品画像・URL の利用目的

**不正検知時**

不正検知の詳細ロジックを公開する必要はないが、端末情報や利用履歴を不正防止目的で利用することは明記する。

### 6-20. 禁止する実装

- 同意していないマーケティングへの利用
- 配送先住所を広告配信へ利用
- Pro 購入情報を Unit 付与条件へ利用
- 不必要な正確な位置情報の取得
- 端末の連絡先を無断取得
- 外部 AI へ氏名・住所を送信
- 個人情報を開発用データとしてそのまま複製
- 退会後も公開プロフィールを残す
- 同一 IP だけで複数アカウントと断定
- プライバシーポリシーにない目的での利用
- 第三者への個人データ販売
- 広告目的のデータ提供を「サービス提供」と一括表記する

### 6-21. プライバシーポリシーの構成

最終的なプライバシーポリシーは以下の構成とする。

9. 未成年者の利用を認める場合、アカウント作成、Pro 課金、海外への配送情報提供について、何歳未満で保護者同意が必要ですか。

11. プライバシーポリシーとは別に、外国提供への同意画面、外部送信一覧、AI 利用説明等を設ける必要がありますか。  
12. 2026年7月公布の改正個人情報保護法について、Uniterz のリリース時点または将来の施行時に追加対応が必要となる事項はありますか。

## 7. Apple・Google の課金・審査規約

以下は、2026年7月23日時点の Apple・Google 公式ポリシーを基にした、弁護士・ストア審査前の暫定設計とする。Apple の App Review Guidelines は 2026年6月8日に更新されているため、実際の申請直前にも再確認する。

### 7-1. 基本方針

Uniterz では、次の 3つをストア審査上も明確に分離する。

| 区分 | ストア上の扱い |
|---|---|
| Pro 機能 | 有料のデジタル機能としてストア課金を使用 |
| Unit | 購入できない無償報酬として管理 |
| NBA 商品 | Unit 交換後に運営が外部で購入する現物商品 |

基本構造は以下とする。

```
ストア課金
  ↓
Pro の分析・通知・レポート・ビジュアルを提供

無料の予想・ランキング
  ↓
成績等により Unit を無償付与
  ↓
Unit で現物商品の交換を申請
```

以下の接続は作らない。

- Pro 購入 → Unit 付与
- Pro 購入 → 商品交換権
- Pro 購入 → ランキング加点
- 現金 → Unit 購入
- 有料 Unit → 予想参加
- 有料参加 → 現物商品の獲得

Apple はアプリ内のデジタル機能・コンテンツの解除にアプリ内課金を要求し、Google Play もアプリ内の機能、デジタルコンテンツ、サブスクリプションについて原則として Google Play Billing を要求している。

### 7-2. Pro 課金の商品区分

| プラン | 料金 | 契約期間 | 自動更新 | 無料体験 | 月次レポート |
|---|---|---|---|---|---|
| Weekly Plan | 280円 | 7日間 | あり | 初回対象者に 7日間 | なし |
| Monthly Plan | 780円 | 1か月 | あり | 初回対象者に 7日間 | あり |
| Season Pass | 5,000円 | 対象 NBA シーズン終了まで | なし | なし | あり |

Apple では、自動更新サブスクリプションの最低期間は 7日間であり、継続的な価値を提供する必要がある。Weekly Plan は 7日間のため、期間要件には適合する。

### 7-3. Apple での商品設定

#### Weekly・Monthly

Weekly と Monthly は、自動更新サブスクリプションとして登録する。

同一の Pro 利用権を提供するため、原則として同じサブスクリプショングループに登録する。

これにより、ユーザーが Weekly と Monthly を重複して契約しにくい構造にする。

Apple は、同じ内容の複数プランについて、ユーザーが意図せず重複契約しないよう、円滑なアップグレード・ダウングレード設計を求めている。

#### Season Pass

Apple では、Season Pass を非自動更新サブスクリプションとして登録する案を第一候補とする。

Apple の非自動更新サブスクリプションは、特定期間だけサービスやコンテンツへアクセスさせる商品として用意されている。

ただし、Uniterz の Season Pass は、

- 購入日から一定期間

ではなく、

- 全ユーザー共通のシーズン終了日まで

という特殊な設計である。

そのため、以下を Apple へ確認する。

- 非自動更新サブスクリプションとして登録できるか
- 購入時期により利用可能期間が異なっても問題ないか
- App Store の商品説明に具体的な終了日を掲載すれば足りるか
- シーズン途中で価格を変更する必要があるか
- 同一商品を次シーズンに再利用できるか、新しい商品 ID が必要か

Season Pass を永続利用の商品として扱う Non-Consumable にすることは避け、期間限定利用権に適した商品区分を Apple へ確認する。

### 7-4. Google Play での商品設定

#### Weekly・Monthly

Weekly と Monthly は、Google Play の自動更新サブスクリプションとして登録する。

同一の Pro 権限を提供するプランとして管理し、以下を防止する。

- Weekly と Monthly の重複契約
- Monthly と Season Pass の重複購入
- プラン変更時の二重請求
- 解約済みだが有効期間中の誤購入

Google Play は、サブスクリプションの価格、請求周期、自動更新条件、利用内容を明確に表示するよう求めている。

#### Season Pass

Google Play では、以下のいずれかを候補とする。

- 自動更新しないプリペイド型サブスクリプション
- 期間限定利用権を付与する一回購入商品
- Google Play が認める別の商品構成

Google Play のプリペイドプランは自動更新されず、有効期限で終了する仕組みを持つ。

ただし、Google Play のプリペイドプランも通常は購入時から一定期間を付与する設計であるため、全ユーザー共通のシーズン終了日にできるかは別途確認する。

### 7-5. Season Pass の重要な未確定事項

Season Pass は、現在の課金設計で最もストア確認が必要な部分とする。

例えば、次の 2人が同じ 5,000円で購入する。

- シーズン開幕日に購入したユーザー
- シーズン終了 1か月前に購入したユーザー

後者は利用期間が大幅に短くなる。

購入前に明確に表示していても、ストア側から不合理な商品構成や誤認表示と判断されないかを確認する。

**必須表示**

- Season Pass は、購入日にかかわらず 2027年○月○日に終了します。
- シーズン途中で購入した場合も、料金の日割り計算や利用期間の延長はありません。
- 次シーズンへの自動更新はありません。

必要に応じて、シーズン後半に価格を下げることも検討する。ただし、価格変更の要否は弁護士とストアへ確認して決める。

### 7-6. 7日間無料体験

Weekly・Monthly の無料体験は、Apple・Google の正式な無料体験機能を利用する。

アプリ内部だけで無料期間を管理し、ストア上では即時課金されるような独自設計は行わない。

購入前に以下を表示する。

- 無料体験期間：7日間
- 選択したプラン
- 無料体験終了後の料金
- 請求周期
- 自動更新されること
- 解約方法
- 無料期間中に解約すれば次回請求を止められること
- Weekly では月次レポートを利用できないこと

Apple では、無料体験は自動更新サブスクリプションの紹介オファーとして設定でき、紹介オファーの利用資格はサブスクリプショングループ単位で確認できる。

Google Play も、無料体験終了後の有料移行、料金、解約方法を登録前に明確に説明するよう求めている。

### 7-7. 無料体験の利用資格

無料体験は、原則として 1ユーザー 1回とする。

ただし、判定は Uniterz のユーザー ID だけに依存せず、ストアが返す利用資格を優先する。

以下の方法による無料体験の繰返しを防止する。

- Uniterz アカウントの作り直し
- アプリの再インストール
- メールアドレス変更
- Weekly 体験後に Monthly 体験を再取得
- 退会後の再登録

Apple では、紹介オファーの資格はサブスクリプショングループ単位で判定されるため、Weekly と Monthly を同一グループに置くことで、両方の無料体験を重複して取得するリスクを抑える。

### 7-10. 購入情報のサーバー検証

端末から「購入成功」が返っただけでは、Pro を有効化しない。

以下の流れとする。

```
ユーザーがストアで購入
  ↓
端末が購入情報をサーバーへ送信
  ↓
サーバーが Apple・Google へ照会
  ↓
購入状態、商品、期限、返金状態を確認
  ↓
Pro 利用権を有効化
```

保存項目：

- プラットフォーム
- 商品 ID
- 取引 ID・注文 ID
- 購入トークン
- 初回購入日時
- 現在の有効期限
- 自動更新状態
- 無料体験状態
- 猶予期間
- 支払保留状態
- 解約状態
- 返金・取消し状態
- 最終検証日時

Apple では App Store Server Notifications V2、Google では Real-time Developer Notifications を使用し、更新、解約、失効、返金等の変更をサーバーへ反映する。

### 7-11. Pro 権限の判定

アプリ画面上の表示ではなく、サーバーの権限情報を基準にする。

```
entitlementStatus
- active
- trial
- grace_period
- billing_retry
- canceled_active
- expired
- refunded
- revoked
```

例：

- 解約済みだが期限前：Pro 利用可能
- 支払猶予期間：ストア仕様に応じて利用可能
- 期限切れ：Pro 停止
- 全額返金：原則として Pro 停止
- チャージバック：Pro 停止・調査
- 購入情報未検証：Pro を有効化しない

### 7-14. プラン変更

**Weekly から Monthly**

- ストアのプラン変更処理を使用
- 適用日時と請求額をストア表示に合わせる
- 独自に二重請求しない

**Monthly から Weekly**

- 現契約期間終了後の適用を基本とする

**Weekly・Monthly から Season Pass**

### 7-15. Web 決済

V1 では、iOS・Android アプリ内から購入する Pro は、原則として各ストア課金を使用する。

アプリ内に以下を設置しない。

- クレジットカード決済ページ
- Stripe 等への購入リンク
- Web 版の方が安いという表示
- 外部サイトで Pro を購入するボタン
- QR コードによる外部決済誘導

Apple・Google はいずれも、対象地域の特別プログラム等を除き、アプリ内デジタル機能の購入を外部決済へ誘導することを制限している。

将来的に Web 決済を導入する場合は、国・地域別の外部リンク制度、手数料、ユーザー選択型決済等を改めて確認する。

### 7-16. 現物商品とストア課金

NBA ジャージ等は、アプリ内でユーザーへ販売する商品ではない。

ユーザーは現金を支払わず、無償で取得した Unit によって交換申請する。

したがって、以下の構造とする。

```
Unit 交換申請
  ↓
運営が外部の正規販売店で商品を購入
  ↓
ユーザーへ配送
```

Apple は、アプリ外で消費される現物商品を販売する場合、アプリ内課金ではなく Apple Pay 等の決済方法を使うよう定めている。Google Play も現物商品の購入には Play Billing を使用しないとしている。

ただし、Uniterz ではユーザーから商品代金を受け取らないため、現時点では現物商品の決済処理自体をアプリ内に設けない。

### 7-31. 暫定評価

| 論点 | 暫定評価 |
|---|---|
| Weekly 自動更新 | Apple の最低 7日要件を満たす |
| Monthly 自動更新 | 標準的なサブスク構成 |
| 7日無料体験 | 明確な自動課金表示が必要 |
| Season Pass | 商品区分と共通終了日の確認が必要 |
| Pro 課金 | ストア課金を使用 |
| Unit | 無償・購入不可を維持 |
| 現物商品 | ストア内で販売しない |
| スポーツ予想 | 賭け・損失・換金を設けない |
| ランキング報酬 | 公式ルールとストア非関与表示が必要 |
| UGC | 通報・ブロック・モデレーションが必要 |
| アカウント削除 | アプリ内と Web の両方を実装 |
| NBA データ | 商用利用権の証拠を準備 |

最大の審査論点は、次の 3つとする。

1. Pro 課金と Unit・現物商品が実質的に接続していないか
2. Season Pass の固定終了日をどの商品区分で販売するか
3. 無料予想・Unit・商品交換が賭博または有料コンテストに見えないか

### 7-32. 弁護士・ストアへの確認事項

1. Pro 料金が分析、通知、レポート、ビジュアル機能のみの対価であり、Unit 付与、ランキング、商品交換条件を Free と同一にする場合、Apple・Google のリアルマネーゲームまたは有料コンテスト規制に抵触する可能性がありますか。  
2. 無償で付与され、購入・換金・譲渡・賭け入れができない Unit を、現物商品の交換申請に使用する制度は、Apple・Google のアプリ内通貨またはロイヤルティ制度としてどのように扱われますか。  
3. Season Pass を購入日にかかわらず同一シーズン終了日に失効させる場合、Apple では非自動更新サブスクリプション、Google ではプリペイドサブスクリプションまたは一回購入商品のどれを使用すべきですか。  
4. シーズン途中の購入者も 5,000円とする設計について、ストアの誤認表示、不合理な価格または消費者保護上の問題がありますか。  
5. Weekly と Monthly を同一サブスクリプショングループまたは同一 Pro 権限として管理し、無料体験を合計 1回に制限する設計は適切ですか。  
6. Apple・Google の審査において、ランキング、Unit、商品交換の公式ルールにはどの項目を記載すべきですか。  
7. アプリ内に NBA ジャージ等の商品画像を掲載せず、ユーザーが正規販売店の商品 URL を入力する方式に問題がありますか。  
8. 「予想倍率」や「難易度係数」という表示が、スポーツベッティングのオッズと誤認される可能性がありますか。  
9. App Review Notes および Google Play 審査資料として、どの契約書、API 利用許諾、商品交換規約、画面資料を提出すべきですか。  
10. 将来的に Web 版で Pro を販売する場合、iOS・Android アプリで既存 Web 購入者へ Pro 機能を提供することや、Web 決済へ案内することにどのような制限がありますか。
