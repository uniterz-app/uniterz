# プレシーズン確認チェックリスト

> 作成: 2026-09-24  
> 目的: プレシーズン期間に本番相当の動きを通し、開幕前に穴を潰す。  
> 対象: Web / Native（Play クローズド含む）  
> 関連: [`nba-stats-data-pipeline.md`](nba-stats-data-pipeline.md) · [`referral-design.md`](referral-design.md) · [`pro-insight-design.md`](pro-insight-design.md) · [`preview-to-prod-checklist.md`](preview-to-prod-checklist.md)

---

## 使い方

- プレシーズン試合が入ったら、下から順に ☐ → ☑
- 不具合はチケット／チャットに残し、ここには **結果メモ** だけ追記
- スタッツは **ingest → Firestore → 公開 API**（クライアントから BDL 直叩きは禁止のまま）

## 3. Pro Insight

| # | 確認 | 結果 |
|---|---|---|
| 3.1 | プレシーズン試合カードに INSIGHT タブが出る／出ない方針が意図どおり | ☐ |
| 3.2 | 出る場合: `proBrief` / matchup-insight が試合前に生成される | ☐ |
| 3.3 | Free はロック、Pro は本文が読める | ☐ |
| 3.4 | 欠場・スプリット等の入力データが空のとき、破綻せず空 or 非表示 | ☐ |
| 3.5 | 日次バッチ（本番は 20:00 JST 想定）がプレシーズン対象か／除外かを確認 | ☐ |

メモ: 設計上「プレシーズンは対象外」の記述あり（[`pro-insight-design.md`](pro-insight-design.md)）。**プレシーズンで出すなら明示的にオン**し、出さないなら UI もそれに合わせる。

## 9. プレシーズン期間の優先順（推奨）

1. **試合終了 → 自動判定**（ランキング・Unit の土台）
2. **Box / ライブ**（見てすぐ分かる）
3. **スタッツ日次更新**（積み上がりの見え方）
4. **ランキングが動くこと**
5. **紹介の E2E**
6. **Pro Insight 方針確定＋生成確認**
7. **IAP（端末が揃い次第）**
