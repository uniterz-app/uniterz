## 1. Pro の位置づけ

Pro は、ユーザー自身のスポーツ予想を支援するために、詳細な分析情報、試合直前情報、個人成績レポート、限定ビジュアルを提供する有料プランとする。

Pro は予想の正解、ランキング上昇、Unit 獲得、商品交換を保証するものではない。

### 行わないこと

- 勝者や推奨予想の断言
- 他ユーザーの予想内容の公開
- Pro 会員へのスコアボーナス
- Pro 会員への Unit 増量
- Pro 会員だけが参加できる基本ランキング
- Pro 加入や更新を条件とした Unit 付与
- 「Pro なら Unit を稼ぎやすい」などの宣伝
- 「確実」「鉄板」「絶対に当たる」などの表現

## 2. 料金プラン

| 機能 | Weekly | Monthly | Season Pass |
|---|---|---|---|
| 料金 | 280 円 | 780 円 | 5,000 円 |
| 利用期間 | 7 日間 | 1 か月間 | 対象シーズン終了まで |
| 更新 | 自動更新 | 自動更新 | 買い切り |
| PRO INSIGHT | ○ | ○ | ○ |
| 試合直前アラート | ○ | ○ | ○ |
| 週次レポート | ○ | ○ | ○ |
| 月次レポート | ― | ○ | ○ |
| 通常 Pro Skin | ○ | ○ | ○ |
| Pro バッジ・専用表示 | ○ | ○ | ○ |

Weekly プランには月次レポートを含めない。

価格は税込表示を基本とする。App Store、Google Play、海外地域では、ストアの価格帯、通貨、税金等によって表示価格が異なる場合がある。

## 3. Season Pass

Season Pass は、対象となる NBA シーズン終了まで Pro 機能を利用できる買い切りプランとする。

- 自動更新しない
- 次シーズンへ自動継続しない
- 購入時期にかかわらず終了日は同じ
- 購入画面に対象シーズンと終了日を表示する
- シーズン途中で価格を変更する場合は、購入前に変更後の価格を表示する
- 次シーズンはユーザー自身が改めて購入する

有効な Weekly または Monthly プランがある状態では、二重課金を防ぐ仕組みを設ける。原則として、定期購入期間終了後に Season Pass へ移行する。

---

## 4. 7 日間無料体験

無料体験は、Weekly または Monthly プランの初回利用時に提供する。

- 1 ユーザーにつき原則 1 回
- Season Pass には無料体験を付けない
- 無料体験中も選択したプランの機能を利用できる
- Weekly の無料体験では月次レポートを利用できない
- Monthly の無料体験では月次レポートを利用できる
- 無料体験終了後は選択したプランで自動更新する
- 終了日時、初回請求日、請求金額を購入前に表示する
- 無料体験中に解約した場合も、原則として無料期間終了まで利用できる
- 複数アカウントによる無料体験の重複利用を禁止する

最終的な無料体験の適用可否や請求日時は、各ストアの購入情報を基準とする。

## 5. PRO INSIGHT

無料画面で確認できるデータを基に、今回の試合で重要な分析を 3〜5 件に絞って表示する。

### 主なカード

- 試合全体の要約
- MATCHUP EDGE
- RECENT CHANGE
- INJURY IMPACT
- SCHEDULE IMPACT
- UPSET / CLOSE GAME FACTOR

各カードには、分析の根拠となる数値を表示する。

試合ごとに重要度を判定し、必要なカードだけを表示する。重要な情報がない場合は、無理にカードを作成しない。

### 表示しないもの

- 推奨する勝敗予想
- 推奨スコア
- 的中を保証する表現
- 他ユーザーの予想
- AI による勝者の断定

PRO INSIGHT は参考情報であり、最終的な予想はユーザー自身が行う。

---

## 6. 試合直前アラート

予想を見直す必要性が高い変化のみを通知する。

### Pro 対象通知

- 重要選手の出場ステータス変更
- 影響の大きいスターター変更
- 複数情報のまとめ通知
- PRO INSIGHT の重要な更新
- 予想済み試合の再確認通知
- 詳細な通知条件や時間帯設定

### Free でも利用できる通知

- 未予想試合の締切 30 分前通知
- お気に入りチームの試合開始通知

通知タップ後は、対象試合の予想画面または PRO INSIGHT へ直接遷移させる。

通知は端末設定、通信環境、外部データの更新状況等によって遅延または未達となる可能性があり、到達を保証しない。

## 7. 個人週次レポート

Weekly、Monthly、Season Pass の全プランで提供する。

### 対象期間

月曜日 0 時から日曜日 23 時 59 分までの JST とする。

- 進行中は毎日更新する（`live`）
- 翌月曜日に最終確定する（`final`）
- プッシュ通知は確定時のみ
- 無料体験初日から進行中レポートを閲覧できる
- V1 は NBA のみを対象とする

### 画面構成

1. 今週の結果  
2. 部門パフォーマンス  
3. 順位変動  
4. ライバル  
5. 今週の診断  

#### 今週の結果

- 週間順位 / 順位変動 / TOP% / 獲得ポイント / 予想数 / 勝敗
- `live` では前日比、`final` では前週比

#### 部門パフォーマンス

WIN / SCORER / UPSET。各部門の成績・前週比・部門順位。最低参加数未達は参考記録。

#### 順位変動

先週終了時の順位と現在順位を比較。抜いた / 抜かれた。初期各 3 人、展開後最大 30 人。

#### ライバル

次のターゲット / 背後の脅威 / ポイント差。対象なしは非表示。

#### 今週の診断

今週の総括 + 次週の焦点。深い分析は月次へ。

### 週次に含めないもの

- レーダー・能力チャート
- ベスト予想
- Shadow 機能

---

## 8. 個人月次レポート

Monthly および Season Pass で提供する。Weekly では利用できない。

### 対象期間

暦月の JST とし、翌月 1 日以降に確定する。

- V1 は NBA のみ
- 確定時にプッシュ通知
- 月内順位推移は V1 に含めない
- Shadow 機能は V1 に含めない

### 画面構成

1. 表紙（月間順位 / TOP% / 前月比 / 分析タイプ称号 / タイプ専用ビジュアル）  
2. 数字で見る今月（予想数・pt・勝率・SCORER・UPSET・前月比・全体平均/中央値・上位10%平均）  
3. 能力チャート（WIN / SCORER / UPSET / CONSISTENCY / SELECTIVITY / ACTIVITY・パーセンタイル 0〜100）  
4. 予想のクセ（文章 + 数値）  
5. チーム相性（ピックアップのみ・推した側・獲得 pt 上下位 TOP3・最低2試合）  
6. 月間ハイライト（価値の高いもの最大 3 件）  
7. 今月のサマリー（強み・改善・目標を1本文に統合）

## 9. Pro 限定ビジュアル

Pro 加入中は以下を利用できる。

- 通常 Pro Skin
- Pro バッジ
- My Rank 専用表示
- TOP% 表示
- 詳細 Progress 表示
- Pro 限定 UI
- Pro 限定アニメーション

通常 Pro Skin は Pro 加入中のみ表示する。

解約または有効期限終了後は通常背景へ戻すが、選択履歴は保存する。再加入時には以前のスキンを復元できる。

---

## 10. Achievement Skin

Achievement Skin は、所定の実績達成によって解放される。**無料会員も解放条件を達成できるが、装着および表示には有効な Pro 利用権が必要となる。** Pro 終了後も解放履歴は保存し、再加入後に再び使用できる。

### ルール（確定）

| 項目 | 内容 |
|---|---|
| 解放 | Free・Pro 共通で実績達成と解放は可能 |
| 装着・表示 | **Pro 加入中のみ** |
| Pro 解約後 | 解放履歴と選択状態は保存。表示は通常背景へ戻す |
| 再加入時 | 解放済み Achievement Skin を再び使用可能 |

### 解放条件の例

- 連勝記録
- 週間ランキング 1 位
- 月間ランキング 1 位
- 各部門 TOP10
- シーズン TOP100
- シーズン 1 位
- 累計予想回数
- 継続利用期間

## 11. Free と Pro の共通条件

以下は Free と Pro で同一とする。

- 予想可能回数
- 予想締切
- スコア計算方法
- 個人ランキング参加条件
- グループバトル参加条件
- イベント参加条件
- Unit 付与条件
- Unit 配布量
- 商品交換条件
- Achievement Skin の獲得条件

Pro は、分析情報、レポート、通知機能、限定ビジュアルへの対価とする。

## 12. Pro 利用権の状態

| status | 意味 |
|---|---|
| `trialing` | 無料体験中 |
| `active` | 有料期間中 |
| `grace_period` | 猶予期間 |
| `billing_retry` | 決済失敗・再請求中 |
| `cancelled` | 自動更新停止済みだが利用期間内 |
| `expired` | 利用期間終了 |
| `refunded` | 返金済み |
| `revoked` | 利用権取消し |

自動更新を停止しても、支払い済み期間が終了するまでは Pro 機能を利用できる。

---

## 13. 自動更新と解約

Weekly および Monthly は自動更新とする。

ユーザーが更新を停止しない限り、各ストアが定めるタイミングで次回料金が請求される。

解約は、購入したプラットフォームのサブスクリプション管理画面から行う。

アプリ内には以下を表示する。

- 現在のプラン
- 利用できる機能
- 次回更新日
- 有効期限
- 自動更新の状態
- サブスクリプション管理画面への導線

アプリの削除やアカウント退会だけでは、定期購入が解約されない場合があることを退会画面に表示する。

---

## 14. プラン変更

Weekly から Monthly、Monthly から Weekly への変更は、各ストアの仕様に従う。

変更画面には以下を表示する。

- 現在のプラン / 変更後のプラン
- 変更が反映される日
- 次回請求額
- 現在の利用期間終了日
- 即時変更または次回更新時変更の別

Weekly から Monthly へ変更した場合、月次レポートは Monthly の利用権が有効になった時点から閲覧可能とする。

Season Pass から Weekly または Monthly へ自動移行しない。

---

## 15. 二重購入の防止

同一アカウントで複数の Pro プランが同時に有効にならないようにする。

- 有効な Weekly 利用者には Monthly への変更導線を表示する
- 有効な定期購入がある場合は Season Pass の購入を制限する
- 購入情報の復元機能を用意する
- 異なる端末で購入した場合も、サーバー側で利用権を統合する
- 重複請求が発生した場合は個別に調査する

---

## 16. 返金

App Store または Google Play 経由の購入は、原則として各ストアの返金手続きに従う。

- ユーザー都合による途中解約では日割り返金を行わない
- 解約後も支払い済み期間終了まで利用できる
- 重複請求、重大なシステム障害等は個別に確認する
- 法令上必要な場合は適用法令に従う
- 返金または決済取消しが確認された場合は Pro 利用権を終了できる

---

## 17. Pro 終了後の扱い

Pro の有効期限が終了した場合:

| 項目 | 扱い |
|---|---|
| PRO INSIGHT | 閲覧不可 |
| Pro 限定アラート | 停止 |
| 週次・月次レポート | 閲覧不可 |
| 通常 Pro Skin | 通常背景へ戻す |
| Achievement Skin | 表示は通常背景へ戻す（解放履歴・選択は保存） |
| Pro バッジ・専用表示 | 非表示 |
| 予想・ランキング・Unit・商品交換 | 引き続き利用可 |

過去に生成したレポートデータや Pro Skin / Achievement Skin の選択履歴は保存し、再加入後に再表示できるようにする。

---

## 18. データと分析に関する注意事項

PRO INSIGHT、レポート、通知は、公式記録、外部データ API、独自ロジック、AI 処理等を利用して作成する。

### 保証しないもの

- データの完全性 / リアルタイム性 / 分析内容の正確性
- 試合結果との一致 / 予想の的中 / ランキング上昇 / Unit 獲得 / 通知の到達

公式記録の訂正、API 障害、情報更新の遅延等によって、表示内容が変更される場合がある。

---

## 19. アカウント共有と不正利用

Pro 利用権は、購入した本人のアカウントにのみ適用する。

禁止: アカウント貸与・共有、購入情報の不正利用、無料体験目的の複数アカウント、決済情報の不正使用、Pro 機能の不正取得、Pro 情報の組織的な転載や再販売。

重大な違反が確認された場合、Pro 機能の停止、利用権取消し、アカウント停止等の措置を行える。

---

## 20. サービス変更・停止

運営は、分析項目、レポート構成、通知条件、Pro Skin 等を改善または変更できる。

重大な変更（料金・課金周期・利用期間・主要機能廃止・Season Pass 終了日）は、原則として事前に告知する。

メンテナンス、外部 API 障害、災害その他の事情によって、一時的に Pro 機能を停止する場合がある。

---

## 21. 購入画面の表示事項

購入確定前に以下を表示する。

- プラン名 / 利用できる機能 / 月次レポート提供の有無
- 料金 / 課金周期 / 利用期間
- 無料体験期間 / 無料体験終了後の料金 / 初回請求予定日
- 自動更新の有無 / 解約方法
- Season Pass の対象シーズンと終了日
- 返金方針 / 利用規約 / プライバシーポリシー / 特定商取引法に基づく表記

購入ボタン付近には、料金、自動更新条件、無料体験終了後の請求内容を明確に表示する。

---

## 22. 課金画面で使用しない表現

使用しない: Pro なら予想が当たりやすい / Unit を効率よく獲得 / ランキングで有利 / ユニフォーム獲得への近道 / 勝てる予想を提供 / 絶対に当たる / 推奨予想 / AI が勝者を決定

使用する表現の基本: 詳細データを確認できる / 試合の重要な変化を把握できる / 自分の予想成績を分析できる / 予想を見直すための参考情報 / 限定ビジュアルを利用できる

---

## 23. 実装データ

### 利用権フィールド（最低限）

- `planType`: weekly / monthly / season
- `platform`: ios / android / web
- `status`
- `trialStartAt` / `trialEndAt`
- `purchasedAt`
- `currentPeriodStartAt` / `currentPeriodEndAt`
- `seasonId` / `seasonEndAt`
- `autoRenew` / `cancelAtPeriodEnd`
- `storeTransactionId` / `originalTransactionId`
- `lastVerifiedAt`

### 機能権限（プランごと）

- `canViewProInsight`
- `canUseProAlerts`
- `canViewWeeklyReport`
- `canViewMonthlyReport`
- `canUseProSkin`
- `canUseProVisuals`

利用権の判定は端末内の情報だけで行わず、ストアの購入情報をサーバー側で検証する。

---

## 24. 弁護士への確認事項

- 7 日間無料体験と自動更新の表示方法
- Weekly、Monthly、Season Pass の販売方法
- Weekly に月次レポートを含めない表示方法
- 特定商取引法に基づく表示内容
- 解約・返金条件
- 海外ユーザー向け価格設定
- PRO INSIGHT の広告表現
- Pro と Unit・商品交換制度が法的に分離されているか
- 利用規約、プライバシーポリシーとの整合性
- アプリ内課金と Web 課金を併用する場合の設計
