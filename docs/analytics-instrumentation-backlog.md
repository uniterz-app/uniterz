# アプリ分析ツール・計測設計 — あとでやるメモ

ユーザー確定（2026-09-12）: **次にやることは、アプリに分析ツールを入れて計測設計する。**  
Pro Insight / スタッツ周りの続きより先に着手する想定。着手まで触らない。

## ゴール

- プロダクト判断に使えるイベント・ファネルを定義する
- Web（モバイル Web）と Native で揃った計測を入れる
- ダッシュボード / エクスポートで見られる状態にする

## 着手時に決めること

| 項目 | メモ |
|---|---|
| ツール | 候補を比較して1本に決める（例: Amplitude / Mixpanel / PostHog / Firebase Analytics 等） |
| 対象面 | Web · Native ·（必要なら）サーバー側イベント |
| 必須イベント | 予想投稿、Pro 導線、Pro Insight 閲覧、予想ツールタブ、通知許可、課金 など |
| PII | uid の扱い、オプトアウト、規約・プライバシーとの整合 |
| 環境 | dev / staging / prod のキー分離 |

## やらない（このメモの段階）

- ツール契約や本番キー投入の先走り
- 計測と無関係なリファクタ
