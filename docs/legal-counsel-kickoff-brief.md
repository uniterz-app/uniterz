## 1. サービス一言

Uniterz は、ユーザーがスポーツ（初期は NBA）の試合結果を**無料で予想**し、成績を競うアプリです。  
有料の **Pro** は、予想を助ける**分析・通知・レポート・見た目**を提供します（正解保証なし）。  
ランキング上位など条件達成者に、運営が **Unit** を無償付与し、貯めた Unit で運営指定の NBA 関連グッズと交換できます。

「予想に金を賭けさせる」サービスではありません。

## A. アプリ設計：ランキング → Unit → 指定商品

### 流れ（説明用）

```
① 試合前に無料で予想を投稿（現金・Unit の賭けなし）
② 試合後、公式結果でスコア（pt）化
③ 週間／月間などのランキングを算出
④ 上位者などへ、運営が Unit を無償付与
⑤ ユーザーが Unit を使い、運営指定の商品区分と交換申請
⑥ 運営が事業資金で正規店から購入し、ユーザーへ配送
```

### 設計上の前提（ここが法務の前提事実）

| # | 前提 |
|---|---|
| 1 | 予想参加に参加料・購入 Unit・保有 Unit の消費は **ない** |
| 2 | 予想が外れても、ユーザーの財産・Unit は **減らない** |
| 3 | 商品代金は参加者の課金を集めた賞金プールではなく、**運営の事業資金** |
| 4 | Free / Pro で、予想回数・スコア計算・ランキング条件・Unit 付与量・商品交換条件は **同一** |
| 5 | Pro 料金は分析等の対価であり、Unit 付与・ランキング優遇には **つながらない** |
| 6 | Unit の購入・換金・ユーザー間譲渡・予想への使用は **しない** |

### 数字感（仮・設計値）

| 項目 | 例 |
|---|---|
| 週間 Unit 対象 | 上位 20 人程度 |
| 月間 Unit 対象 | 上位 50 人程度 |
| ジャージ交換 | 1,000 Unit ／ 商品価格上限 約 25,000 円 |
| Tシャツ／キャップ | 600／300 Unit（上限はそれより低い） |
| Pro 例 | Weekly 280 円／Monthly 780 円／Season Pass 5,000 円 |

### A で聞きたい質問

1. 上記の一連の設計は、**賭博罪・賭博場開張等**に該当し得ますか。該当リスクを下げるために必須の条件は何ですか。  
2. ランキング上位への Unit・商品は、**景品表示法**上どのように評価されますか（オープン懸賞／取引付随の懸賞／その他）。  
3. 景品規制の対象になる場合、**商品上限 25,000 円**や配布総量は維持できますか。できない場合の現実的な設計変更案は何ですか。  
4. 無償付与の Unit → 商品交換は、**資金決済法**上の前払式支払手段に該当しますか。該当しないための必須条件は何ですか。  
5. Unit の本番付与・商品交換公開の前に、**書面判断が必要な論点**を優先度付きで教えてください。

## B. スコア（pt）と Unit の役割

アプリ内には性質の違う 2 つの数があります。**混同しないこと**が設計の中核です。

### 対照表（説明の正）

| | **スコア（pt / Points）** | **Unit** |
|---|---|---|
| 何か | 予想成績の点数 | 運営が付与するアプリ内報酬 |
| どう増える | 予想が公式結果と照合され、独自ロジックで加点 | ランキング上位・招待達成など、**運営が定めた条件**で無償付与 |
| 用途 | 成績表示・ランキング算出・（結果として）Unit 付与対象の決定 | **運営が指定する商品との交換のみ** |
| 金銭的価値 | **持たない** | 現金そのものではない（商品交換に使える経済上の利益になり得る点は要確認） |
| 購入 | **不可** | **不可** |
| 換金・払戻し | **不可** | **不可** |
| ユーザー間の譲渡・売買 | **不可** | **不可** |
| 予想への賭け・消費 | **しない** | **しない** |
| 予想失敗時 | その試合の加点がないだけ（残高消費なし） | **減らない** |
| Pro 料金との関係 | なし（計算式も Free と同一） | **付与しない／倍率も上げない** |

### 画面・規約で伝えたい一文（案）

> スコア（pt）はランキング用の成績指標であり、金銭的価値はありません。購入・換金・譲渡・商品交換はできません。  
> Unit は運営が無償で付与するアプリ内報酬です。購入・換金・ユーザー間譲渡はできません。運営が指定する商品との交換にのみ使用できます。Pro 利用料金は Unit の対価ではありません。

### B で聞きたい質問

1. 上記の **スコア／Unit の役割分離**は、法的に問題ない整理ですか。規約・画面で必須の表現はありますか。  
2. Unit は「金銭的価値を持たない」と書ける範囲はどこまでですか（商品交換できる以上、景表・資金決済ではどう扱うべきか）。  
3. スコアも Unit も購入・譲渡・換金不可、という制限を維持する前提で、**やってはいけない変更**（例: Unit 販売、Pro 加入ボーナス Unit）を確認したいです。

詳細: [`service-overview.md`](service-overview.md), [`prediction-and-scoring.md`](prediction-and-scoring.md)

## C. PRO INSIGHT のリーガルチェック

### 何か

Pro 会員向けの**試合前分析**。無料データ等を整理し、試合ごとに重要な結論を数個出す。

| やる | やらない |
|---|---|
| MATCHUP EDGE / RECENT CHANGE / INJURY 等の分析カード | 勝者の断言 |
| 根拠となる数字の表示 | 「推奨予想」「鉄板」「絶対」 |
| ユーザーが自分で予想を決める材料 | 他ユーザーの予想内容の公開 |
| | Pro だけのスコアボーナス／Unit 増量 |

### なぜ法務確認が必要か（当社の懸念）

- Free と Pro でランキング・Unit ルールは同一でも、  
- PRO INSIGHT が「有料でヒントが分かる／懸賞（ランキング）で有利になる」と評価されると、  
- Unit・商品が **Pro 取引に付随する景品**とみなされ、景品最高額・総額規制に触れる可能性がある。

商品価格上限 25,000 円のジャージは、取引価額を Weekly 280 円・Monthly 780 円と見ると、一般懸賞の上限を超え得る（当社試算）。

### C で聞きたい質問

1. 勝者・推奨予想を出さない PRO INSIGHT でも、景品表示法上「購入により答えやヒントが分かる」事情になり得ますか。  
2. なり得る場合、現行の Unit・商品設計と **両立できますか**。できない場合の選択肢（機能制限／商品上限引き下げ／訴求・画面の完全分離／Unit を Pro と時間的・表示的に切り離す等）は何ですか。  
3. Pro 課金画面から Unit・商品・ランキング報酬の訴求を出さない、という運用はリスク低減として有効ですか。必須ですか。  
4. PRO INSIGHT のコピー・UI で、今の段階で避けるべき表現・構成はありますか。

詳細: [`pro-subscription-plan.md`](pro-subscription-plan.md) § PRO INSIGHT, [`legal-risk-review.md`](legal-risk-review.md) §2

## 2. お金・Pro・Unit の分離図（補足）

```
ユーザーのお金 → ストア決済 → Pro 利用権のみ（Unit は増えない）

無料予想・同一ルールのランキング
  → 運営が条件達成者へ Unit を無償付与
  → 指定商品との交換（運営が購入・配送）
```

**作らない接続:** Pro→Unit、現金→Unit 購入、Unit→現金／譲渡／予想への賭け、「Pro なら Unit を稼ぎやすい」訴求
